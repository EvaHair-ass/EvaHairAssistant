# Как запустить «Мою мастерскую» на телефоне и компьютере

Готовая версия лежит в папке `docs/`. Это обычный сайт из нескольких файлов, его нужно один раз выложить в интернет. После этого приложение открывается по ссылке и ставится на телефон и компьютер.

## Шаг 1. Выложить в интернет (бесплатно, 5 минут)

**Самый простой способ: Netlify Drop**
1. Скачай репозиторий архивом с GitHub (кнопка «Code» → «Download ZIP») и распакуй.
2. Открой app.netlify.com/drop (нужна бесплатная регистрация на netlify.com).
3. Перетащи папку `docs` на страницу. Через минуту появится ссылка вида `https://что-то.netlify.app`.

**Другие варианты** (подойдут, когда захочешь, чтобы обновления выкладывались сами):
- Cloudflare Pages или Netlify, подключённые к репозиторию: папка публикации `docs`, команда сборки не нужна.
- GitHub Pages: Settings → Pages → ветка и папка `/docs`. Для закрытого репозитория на бесплатном тарифе это может быть недоступно, проверь.

## Шаг 2. Перенести свои данные
Данные лежат в браузере, у каждого адреса они свои. Поэтому на новом адресе приложение сначала пустое (с примерами).
1. В старой версии: «Ещё» → «Сохранить» → «Скопировать». Вставь текст в заметки.
2. В новой версии: «Ещё» → «Восстановить» → вставь текст → «Заменить данные».

## Шаг 3. Поставить на телефон и компьютер
- **iPhone (Safari):** кнопка «Поделиться» → «На экран Домой».
- **Android (Chrome):** меню ⋮ → «Установить приложение».
- **Компьютер (Chrome, Edge):** значок установки справа в адресной строке.

После установки приложение открывается как обычное и работает без интернета.

## Важно знать
- Пока данные на каждом устройстве свои: телефон и компьютер не синхронизируются. Облако и вход по почте будут следующим этапом.
- Регулярно делай «Сохранить» (копию данных). Насколько я знаю, на iPhone сайт из вкладки Safari может терять данные, если им долго не пользоваться, а установленное на экран «Домой» приложение защищено лучше. Но копия страхует от всего.
- Чтобы выпустить обновление: измени `prototype/index.html`, запусти `python3 tools/build_pwa.py` и заново выложи папку `docs`.
