# Языки и стиль общения: Melaymade

Этот файл фиксирует правила текстов. Сверяться с ним при переводе приложения и писем.

## Бренд
- Название **Melaymade** (одним словом, везде одинаково). Не «Melay Made», не «MelayMade».
- В турецком к названию добавляются окончания через апостроф: *Melaymade'e hoş geldiniz*.

## Турецкий (проверено носителем)
- Обращение: **всегда «siz»** (вежливое). Тон: доброжелательный, современный, профессиональный.
- Кнопки: короткие, с понятным действием, с заглавных букв: «Kaydet», «Hesapla», «Stoka Ekle», «Şifremi Sıfırla», «E-postamı Doğrula».
- Терминология: **Malzeme Stoku** (склад материалов), **Maliyet Hesaplama** (расчёт себестоимости), **Fiyatlandırma** (ценообразование), **Alışveriş Listesi** (список покупок).
- Вежливое «siz» не делает приложение холодным: для продукта, которому доверяют учёт и расчёты, это уместно.
- Перед запуском весь турецкий интерфейс снова показать носителю.

## Русский
- Обращение: «ты» (как сейчас в приложении).
- Избегать рода в формулировках, где можно: вместо «если ты не регистрировалась» писать «если аккаунт создавала не ты».

## Английский
- Дружелюбное «you», простые короткие фразы. Кнопки в стиле «Save», «Calculate», «Add to stock».

## Письма Supabase (один шаблон на три языка: русский, турецкий, английский)
Утверждённые тексты: см. шаблоны «Reset password» и «Confirm sign up» в Supabase (Authentication → Emails → Templates).
