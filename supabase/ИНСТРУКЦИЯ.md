# Подключение облака и входа (Supabase): пошагово

Что это даёт: вход по почте, данные в облаке (телефон и компьютер синхронизируются), фото в защищённом хранилище, доступ по подписке. Каждая пользовательница видит только свои данные.

## 1. Создать проект (10 минут)
1. Открой supabase.com → **Start your project** → зарегистрируйся (через GitHub или почту).
2. **New project**: название, например, `moya-masterskaya`. Регион выбери ближайший к покупательницам в Европе (например, Frankfurt). Придумай пароль базы и сохрани его в надёжном месте. Мне он не нужен.
3. Подожди, пока проект создастся (1–2 минуты).

## 2. Создать таблицы
1. Слева **SQL Editor** → **New query**.
2. Вставь весь текст файла `supabase/schema.sql` → **Run**. Должно появиться «Success».

## 3. Настроить вход
1. **Authentication** → **Providers** → **Email**. Для первых проверок можно выключить «Confirm email», тогда регистрация проходит без письма.
2. Перед настоящим запуском включи подтверждение почты и подключи свою почтовую службу (**Authentication → SMTP Settings**, например Resend или Brevo). Насколько я знаю, встроенная отправка писем в Supabase имеет жёсткий лимит и не рассчитана на продажи, но проверь это в их документации.
3. **Authentication → URL Configuration**: в **Site URL** впиши адрес, где опубликовано приложение (например, `https://что-то.netlify.app`). Туда же добавь его в **Redirect URLs**.

## 4. Передать мне публичные данные проекта
**Project Settings → API (или Data API)**. Нужны две строки:
- **Project URL**: вида `https://abcdefgh.supabase.co`
- ключ **anon public** (длинный, начинается с `eyJ`)

Их можно присылать в чат: они публичные по задумке Supabase, защиту данных обеспечивают правила из `schema.sql`.
**Никогда не присылай ключ `service_role` и пароль базы.**

## 5. После этого
Я добавлю данные в `supabase/config.json`, пересоберу приложение (`python3 tools/build_pwa.py`), и ты заново выложишь папку `docs` на Netlify.

## 6. Сделать свой аккаунт вечным
Зарегистрируйся в приложении, затем выполни в SQL Editor запрос из конца `schema.sql` (замени почту). Иначе твой доступ закончится вместе с пробным периодом.

## Как включить подписку покупательнице вручную
Файл `выдать_доступ.sql`: меняешь почту и срок, запускаешь в SQL Editor.

## Что стоит знать
- Бесплатный тариф Supabase ограничен (место для базы и фото, насколько я знаю, также проекты без активности могут «засыпать»). Для продажи, скорее всего, понадобится платный тариф. Условия смотри на странице тарифов Supabase.
- Фото и данные покупательниц хранятся на серверах Supabase в выбранном регионе. Это нужно указать в политике конфиденциальности.
- Пробный период по умолчанию 14 дней. Меняется в `schema.sql` (строка `interval '14 days'`).
