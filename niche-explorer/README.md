# Прибыльные ниши

Введи нишу → получи отчёт из пяти разделов → сохрани → вернись к нему позже.

## Запуск

Нужен Node.js 22.13+. Зависимостей нет — `npm install` не требуется.

```bash
cp .env.example .env      # впиши ANTHROPIC_API_KEY
npm start                 # http://localhost:3000
npm test                  # тесты API (с поддельным ИИ, ключ не нужен)
```

## Как устроено

- `server.js` — сервер и API (`/api/analyze`, `/api/reports`).
- `src/ai.js`, `src/prompt.js` — запрос к Claude; ответ приходит строго по схеме (`src/report.js`).
- `src/db.js` — SQLite в `data/niches.db` (папка не попадает в git).
- `public/` — интерфейс без сборки.

## Что важно знать

- **Аккаунтов нет.** Сохранённые исследования привязаны к браузеру (случайный идентификатор в localStorage). Другой браузер или очистка данных сайта — другой список. Если нужен вход с разных устройств, добавляется логином по email поверх той же таблицы `reports`.
- **Лимит анализов** — 10 в час на устройство (`ANALYSES_PER_HOUR`), чтобы не сжечь бюджет API.
- Отчёт — гипотезы ИИ, а не реальная статистика; в интерфейсе это написано.
