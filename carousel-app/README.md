# Создатель сценариев каруселей

Веб-приложение, которое пишет **только тексты** для каруселей в Instagram: слайды, подпись и экспорт для приложения, где ты оформляешь карусели. Графику оно не создаёт.

## Запуск

Нужен Node.js 20.12 или новее.

```bash
cd carousel-app
npm install
cp .env.example .env      # впиши свой ANTHROPIC_API_KEY
npm start                 # http://localhost:3000
```

Проверить интерфейс без ключа можно в демо-режиме (тексты-заглушки): `npm run demo`.

## Как это устроено

- `server.js` отдаёт страницу и ходит к Claude. Ключ хранится только на сервере и в браузер не попадает.
- `shared/core.js` — промпты, проверки и обработчики. Их использует и сервер, и версия-артефакт, так что тексты пишет один и тот же код.
- `public/` — сам интерфейс (обычные HTML, CSS и JS, сборка не нужна).
- `tools/build-artifact.mjs` — собирает всё в один файл `dist/artifact.html` для страницы-артефакта Claude: там ИИ работает через «Спросить Claude» на аккаунте того, кто открыл страницу, без API-ключа.
- Проекты хранятся в браузере (`localStorage`): без аккаунтов, но на другом устройстве или после очистки данных браузера их не будет.
- Модель по умолчанию `claude-opus-5-5`, меняется переменной `CLAUDE_MODEL`.

## Если выкладываешь в интернет

Любой, у кого есть ссылка, тратит твои деньги на ИИ. В сервере есть только простой лимит запросов с одного IP (`RATE_LIMIT_PER_10MIN`, по умолчанию 60 за 10 минут). Для публичного доступа закрой страницу паролем или входом на уровне хостинга.
